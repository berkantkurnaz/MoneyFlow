# MoneyFlow 💜

Modern ve duyarlı bir kişisel finans takip uygulaması.

## 📌 Proje Hakkında

MoneyFlow, kullanıcıların gelirlerini, giderlerini ve aylık bütçelerini kolayca takip etmelerine yardımcı olmak için geliştirilmiş bir kişisel finans uygulamasıdır.

## ✨ Özellikler

- Gelir ve gider işlemi ekleme, düzenleme ve silme
- Gelir ve giderleri takip etme
- Aylık bütçe belirleme ve yönetme
- Aylık gelir ve gider grafiklerini görüntüleme
- Harcamaları kategorilere göre analiz etme
- Bilgisayar ve mobil cihazlarla uyumlu tasarım
- Verileri LocalStorage kullanarak kaydetme

## 🛠️ Kullanılan Teknolojiler

- React
- Vite
- JavaScript
- Tailwind CSS
- Recharts
- Lucide React
- LocalStorage

## 🚀 Kurulum

Projeyi bilgisayarınıza indirmek için:

```bash
git clone https://github.com/berkantkurnaz/MoneyFlow
```

Proje klasörüne girin:

```bash
cd moneyflow
```

Gerekli paketleri yükleyin:

```bash
npm install
```

Geliştirme sunucusunu başlatın:

```bash
npm run dev
```

## 📦 Derleme

Projeyi yayına hazır hâle getirmek için:

```bash
npm run build
```
